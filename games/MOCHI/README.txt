MOCHI — Phase A Starter

Files: index.html, style.css, game.js

Included: colourful 3D arena, two locally rendered characters (the second is a decorative bot, not an online player), WASD/arrow movement, jump, follow camera, drag-to-look, mouse-wheel zoom, and a mobile touch movement pad.

This is Phase A only; it is NOT online multiplayer yet. Three.js loads from jsDelivr, so internet is required. Upload these files to a new `mochi/` folder in your existing repository; do not overwrite the root index.html or `rivals/` folder. Test through GitHub Pages or a web server, not by opening the HTML as a local file.

Planned URL: https://inter-rivalry.github.io/Inter-Rivalry-BCU/mochi/

Landscape update: MOCHI shows a rotate-phone prompt in portrait mode and tries to lock landscape after tapping the button. Orientation lock depends on browser support; rotating the phone manually works.
